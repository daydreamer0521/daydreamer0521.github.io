antigravity初体验

发表于 2026-02-02 分类于 工具

Google的AI IDE

要求

  • 一台能用的电脑(我的系统是ubuntu20.04)
  • 科学上网工具
  • 一个Google账号(如果是刚注册的账号可能有问题)

安装

  • 在antigravity官网有安装教程

  • 但是我在针对linux ubuntu的第二步出现了问题

    显示apt连不上antigravity要求的源的地址。但是我开了代理，而且用curl测试是可以连接上的。解决方式是给apt也配置代理。步骤如下：

    1. 在科学上网软件里面查看端口号(一般在设置里面)，记住这个端口号。

    2. sudo gedit /etc/apt/apt.conf.d/99proxy

      然后粘贴(xxxx就是查到的端口号)

    3. sudo nano /etc/apt/apt.conf.d/99force-ipv4


    4. sudo rm -rf /var/lib/apt/lists/*
sudo apt update

  • 然后继续官网上的最后一步就安装成功了

登录

登录这一步有点麻烦，在antigravity上点击sign in之后会自动跳转到浏览器继续，但是我在edge浏览器完成登录流程之后没办法定向回到antigravity，换了firefox浏览器之后多出了一步Vierfy，具体就是用安卓手机扫码(需要科学上网)或者接收验证码(大陆手机号也可以)。我扫码之后显示不支持我的手机，因此换成了验证码，Vierfy之后就收到了google antigravity的邮件，证明登录成功了。

使用

antigravity界面和vscode长得一样，原生语言是英文，下载中文插件重启之后就变成中文了(步骤和vscode一样)。关于具体的使用感受，分点来说

  • 交互: 我感觉交互和copilot比较像，但是不如copilot那么方便，比较直观的一点是当agent想要在终端运行某些命令时，我不能马上看到具体要运行的命令是什么，需要在上下文找一下才知道
  • 速度: 不知道是不是网络的问题，我感觉反馈不是特别快，提出一个需求之后需要等待一小段时间才行，这一点和copilot差不多
  • agent: 免费额度有点少，我最开始选的是claude sonnet4.5，生成到一半就告诉我额度用尽了(我以为是这一个模型的额度用尽了，结果发现是claude系列的额度都用尽了)后半部分是gemini 3 pro完成的，感觉也可以理解，可能google像突出自家的模型，而且claude也不便宜。有一个让我很惊喜的地方是agent可以自由打开浏览器查看生成效果(仅限Chrome)，因为copilot做不到。
  • 下面的小游戏是我完全使用antigravity里面的agent实现的，感觉效果还不错，全程没有写一行代码，唯一的工作是等agent写代码，查看效果，告诉agent修改的方向，游戏原型来自戳这里

🎮 互动小游戏：流沙俄罗斯方块

体验一下不一样的俄罗斯方块！在这个版本中，方块会像沙子一样自然下落，消除行后上方的方块会像流沙一样填补空隙。这与 “antigravity”（反重力）形成了有趣的对比 😄

操作说明：

  • 使用方向键 ← → 移动方块
  • 使用 ↑ 键旋转方块
  • 使用 ↓ 键加速下落
  • 按空格键快速下落
  • 按 P 键暂停/继续

移动设备可以使用屏幕上的触摸按钮进行控制。祝你玩得开心！🎉
